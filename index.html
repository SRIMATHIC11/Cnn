How to Use the CNN Visualizer

Controls

  • Select Image: Choose different input images to see how the CNN processes them
  • Animation Speed: Adjust how fast the visualization plays
  • Start Processing: Begin the neural network forward pass animation
  • Step Forward: Move through the network one layer at a time
  • Reset: Return to the initial state

Layer Types

  • Input Layer (Blue): Original image data as a 2D grid
  • Convolutional Layer (Green): Applies filters to detect features
  • Pooling Layer (Yellow): Reduces spatial dimensions
  • Flatten Layer (Purple): Converts 2D data to 1D vector
  • Dense Layer (Orange): Fully connected neural network layer
  • Output Layer (Red): Final classification probabilities

Interaction

  • Mouse: Rotate and zoom the 3D scene
  • Hover: Get detailed information about layers
  • Click: Select specific layers for detailed view
