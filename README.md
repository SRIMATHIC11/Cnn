# 🧠 CNN 3D Visualizer

Interactive 3D demo to understand how a CNN processes images layer by layer.

## 🚀 Quick Start

### 1) Clone
```bash
git clone https://github.com/srimathic11/CNN-3D-Visualizer-main.git
cd CNN-3D-Visualizer-main
```

### 2) Run locally
```bash
python3 -m http.server 8000
```

Or:

```bash
npx serve .
```

### 3) Open
```text
http://localhost:8000
```

## ✨ Features
- 3D CNN architecture visualization
- Step-by-step animation through layers
- Play / Pause / Reset controls
- Adjustable speed
- Live layer info and prediction bars

## 🎮 Controls
- Mouse drag: rotate
- Scroll: zoom
- `Space`: play/pause
- `R`: reset
- `→`: step forward
- `H`: help

## 📁 Main Files
- `index.html`
