# CNN 3D Visualizer

An interactive 3D web application that visually demonstrates how a Convolutional Neural Network (CNN) processes image data for classification. This educational tool provides an intuitive understanding of CNN architecture and operations through engaging 3D animations.

![CNN 3D Visualizer](https://img.shields.io/badge/CNN-3D%20Visualizer-blue) ![Three.js](https://img.shields.io/badge/Three.js-r128-green) ![WebGL](https://img.shields.io/badge/WebGL-Enabled-orange)

## 🌟 Features

### 🎯 Core Functionality
- **Interactive 3D CNN Visualization**: Real-time 3D rendering of CNN layers and operations
- **Layer-by-Layer Processing**: Step through each layer of the network with detailed animations
- **Multiple Input Images**: Choose from different sample images (digits, animals, patterns)
- **Educational Animations**: Visual demonstrations of convolution, pooling, and dense operations
- **Real-time Data Flow**: Animated particles showing data movement between layers

### 🏗️ CNN Architecture Visualization
- **Input Layer**: 2D pixel grid with color-coded intensity values
- **Convolutional Layers**: 3D feature maps with animated filter sweeps
- **Pooling Layers**: Downsampling animations with spatial reduction effects
- **Flatten Layer**: 2D-to-1D transformation visualization
- **Dense Layers**: Fully connected neurons with activation animations
- **Output Layer**: Confidence bars showing classification probabilities

### 🎮 Interactive Controls
- **Play/Pause/Reset**: Full control over animation playback
- **Step-by-Step Mode**: Manual progression through network layers
- **Speed Control**: Adjustable animation speed (0.1x to 3.0x)
- **Layer Selection**: Click on layers for detailed information
- **Camera Controls**: 3D navigation with mouse/touch

### 🎨 Modern UI Design
- **Dark Theme**: Professional dark interface with accent colors
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Real-time Information**: Dynamic layer details and statistics
- **Architecture Overview**: Visual network topology with progress tracking
- **Help System**: Comprehensive user guide and keyboard shortcuts

## 🚀 Quick Start

### Prerequisites
- Modern web browser with WebGL support
- No installation required - runs entirely in the browser

### Running the Application

1. **Clone or Download** the repository:
   ```bash
   git clone https://github.com/your-username/cnn-3d-visualizer.git
   cd cnn-3d-visualizer
   ```

2. **Open in Browser**:
   - Simply open `index.html` in a modern web browser
   - For local development, use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve .
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Start Exploring**:
   - Select an input image from the dropdown
   - Click "Start Processing" to begin the animation
   - Use mouse to rotate and zoom the 3D scene
   - Hover over layers for detailed information

## 🎯 How to Use

### Basic Controls
- **🖱️ Mouse Navigation**: Drag to rotate, scroll to zoom, right-drag to pan
- **⌨️ Keyboard Shortcuts**:
  - `Space`: Play/Pause animation
  - `R`: Reset to beginning
  - `→`: Step forward one layer
  - `↑/↓`: Increase/decrease animation speed
  - `H`: Show help dialog
  - `Esc`: Close modals

### Understanding the Visualization

#### 1. Input Layer (Blue)
- Represents the original image as a 2D grid of pixels
- Each cube's color intensity corresponds to pixel brightness
- Size: 16×16 pixels for demonstration

#### 2. Convolutional Layers (Green)
- Shows feature maps generated by convolution filters
- Animated filters sweep across the input to detect features
- Multiple feature maps represent different learned patterns

#### 3. Pooling Layers (Yellow)
- Demonstrates spatial dimension reduction
- Shows max-pooling operation with shrinking animations
- Preserves important features while reducing data size

#### 4. Flatten Layer (Purple)
- Visualizes the transformation from 2D maps to 1D vector
- Animated reshaping shows how spatial data becomes linear

#### 5. Dense Layers (Orange)
- Fully connected neurons arranged in circular patterns
- Connection animations show information flow
- Activation patterns demonstrate learned representations

#### 6. Output Layer (Red)
- Classification probabilities as colored height bars
- Higher bars indicate higher confidence
- Color coding: Red (low) to Green (high confidence)

### Project Structure
```
CNN/
├── index.html              # Main HTML file
├── styles.css              # CSS styling and animations
├── js/
│   ├── CNNVisualizer.js    # Core 3D scene and rendering
│   ├── LayerComponents.js  # Individual layer visualizations
│   ├── AnimationEngine.js  # Animation system and effects
│   ├── UIController.js     # User interface management
│   └── main.js            # Application initialization
└── README.md              # Documentation
```

### Key Components

#### 🎨 CNNVisualizer
- **Purpose**: Core 3D scene management and rendering
- **Features**: WebGL setup, camera controls, lighting, layer creation
- **Technologies**: Three.js, WebGL, OrbitControls

#### 🧩 LayerComponents
- **Purpose**: Specialized visualization for each layer type
- **Features**: Geometries, materials, data binding, updates
- **Customization**: Easy to extend with new layer types

#### 🎬 AnimationEngine
- **Purpose**: Complex animations and visual effects
- **Features**: Data flow particles, layer transitions, timing control
- **Effects**: Convolution sweeps, pooling animations, activation pulses

#### 🎛️ UIController
- **Purpose**: User interface and interaction management
- **Features**: Control panels, layer information, keyboard shortcuts
- **State Management**: Animation state, user preferences, data flow
